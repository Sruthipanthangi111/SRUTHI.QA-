Today I learned the basics of Git and GitHub as part of my QA Testing learning journey.

## My Learning

I learned how Git tracks changes in a project and how GitHub is used to store and collaborate on repositories.

I also practiced basic branch creation, switching between branches, merging changes, checking commit history, pulling changes, and comparing or restoring files.

## QA Relevance

Git and GitHub are important for QA testers because testers work with application code, test automation scripts, bug fixes, branches, and team collaboration.

Examples:

1. A QA tester can create a branch for automation test changes.
2. A QA tester can pull the latest code before testing a new build.
